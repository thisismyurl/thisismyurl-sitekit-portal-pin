# Site Kit Portal Pin

[![WordPress](https://img.shields.io/badge/WordPress-6.0%2B-blue.svg)](https://wordpress.org/) [![License](https://img.shields.io/badge/License-GPL--2.0--or--later-green.svg)](LICENSE)

Pins the Google Site Kit portal link to the WordPress admin toolbar so you can reach it from any admin screen.

## What it does

- Adds a persistent "Site Kit" link to the WordPress admin toolbar
- Shows on every admin screen, not just the Site Kit dashboard
- Opens the Google Site Kit portal directly
- Runs only when Site Kit is active

## Why it exists

Site Kit puts Google analytics data inside the WordPress dashboard, but the portal link only lives on Site Kit's own screen. If you are working on a post or a settings page, you have to navigate back to the dashboard to get there. This plugin moves the link to the toolbar so it is one click away from wherever you are.

## Requirements

- WordPress 6.0+
- PHP 7.4+
- Google Site Kit (installed and active)

## Installation

1. Install and activate Google Site Kit first.
2. Upload this plugin to `/wp-content/plugins/thisismyurl-sitekit-portal-pin/`.
3. Activate it through the Plugins screen.
4. The toolbar link appears automatically once both plugins are active.
